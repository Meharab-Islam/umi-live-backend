📖 External App & Mobile Integration Guide (README)

Comprehensive developer documentation, webhook payloads, HMAC signature verification, and copy-paste code snippets for integrating Big Eater into Flutter, React Native, iOS, Android, and Web backends.

🚀 1. Integration Architecture Overview

Big Eater provides a Dual-Layer Integration Architecture engineered for maximum security, speed, and cross-platform flexibility:

  • Layer 1: Server-to-Server Webhook (Recommended for Wallets & Balances) — The game server directly triggers authenticated HTTP POST requests to your central API server whenever bets are placed or rounds finish. Transactions cannot be spoofed or bypassed by clients.
  • Layer 2: In-App WebView Bridge (Recommended for UI & Sound FX) — When running Big Eater inside a Flutter or mobile WebView, the game client dispatches instant FlutterChannel.postMessage events for in-app animations, vibrations, and victory banners without needing a round-trip to the server.

👤 2. Passing User / Player ID from your App

When launching the game inside your mobile app's WebView, pass your authenticated user's ID as a URL query parameter (?userId=... or ?sessionId=...):

URL FORMAT 
http://YOUR_GAME_HOST:3000/?userId=USER_882910

The game client automatically binds this user ID to the session. All subsequent database bets, socket events, and server Webhook notifications will include sessionId: "USER_882910", allowing your backend to instantly map results to the user's wallet!

📱 4. Flutter Mobile App Integration (webview_flutter)

Copy and paste this Flutter screen into your mobile app. It embeds the game in a WebView, automatically passes the user's ID, and receives real-time bridge messages:

FLUTTER DART (GameScreen.dart) 
import 'dart:convert';
import 'package:flutter/material.dart';
import 'package:webview_flutter/webview_flutter.dart';

class BigEaterGameScreen extends StatefulWidget {
  final String userId; // Current logged-in user ID in your app

  const BigEaterGameScreen({Key? key, required this.userId}) : super(key: key);

  @override
  State<BigEaterGameScreen> createState() => _BigEaterGameScreenState();
}

class _BigEaterGameScreenState extends State<BigEaterGameScreen> {
  late final WebViewController _controller;

  @override
  void initState() {
    super.initState();
    final gameUrl = 'http://YOUR_SERVER_IP:3000/?userId=${widget.userId}';

    _controller = WebViewController()
      ..setJavaScriptMode(JavaScriptMode.unrestricted)
      ..setBackgroundColor(const Color(0xFF0F1C13))
      ..addJavaScriptChannel(
        'FlutterChannel',
        onMessageReceived: (JavaScriptMessage msg) {
          try {
            final data = jsonDecode(msg.message);
            final event = data['event'];

            if (event == 'bet:placed') {
              print('🪙 Bet placed: ${data['amount']} coins on ${data['foodName']}');
            } else if (event == 'round:result') {
              final bool won = data['won'] ?? false;
              final int winAmount = data['winAmount'] ?? 0;
              final int netProfit = data['netProfit'] ?? 0;

              if (won) {
                ScaffoldMessenger.of(context).showSnackBar(
                  SnackBar(
                    backgroundColor: Colors.amber.shade800,
                    content: Text('🎉 Congratulations! You won $winAmount coins! (+$netProfit)'),
                  ),
                );
              }
            } else if (event == 'recharge') {
              // Open your mobile in-app coin recharge store
              print('Recharge clicked. Current balance: ${data['currentBalance']}');
            } else if (event == 'close') {
              Navigator.of(context).pop();
            }
          } catch (e) {
            print('Bridge message error: $e');
          }
        },
      )
      ..loadRequest(Uri.parse(gameUrl));
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: const Color(0xFF0F1C13),
      body: SafeArea(
        child: WebViewWidget(controller: _controller),
      ),
    );
  }
}

💻 5. Backend Webhook Receiver Implementation

Securely verify the HMAC SHA-256 signature and update player wallets in your database:

Node.js / Express

NODE.JS / EXPRESS 
const express = require('express');
const crypto  = require('crypto');
const app     = express();

app.use(express.json());

const WEBHOOK_SECRET = 'bigeater888_secret'; // Set same key in Admin Panel

app.post('/api/bigeater-webhook', (req, res) => {
  const signature = req.headers['x-bigeater-signature'];
  const event     = req.headers['x-bigeater-event'];

  // Verify HMAC-SHA256 signature
  const expectedSig = crypto
    .createHmac('sha256', WEBHOOK_SECRET)
    .update(JSON.stringify(req.body))
    .digest('hex');

  if (signature !== expectedSig) {
    return res.status(401).json({ error: 'Unauthorized signature' });
  }

  const { data } = req.body;

  if (event === 'bet:placed') {
    console.log(`[BET] User ${data.sessionId} bet ${data.amount} on ${data.foodName}`);
    // Deduct coins or track in your DB
  }

  if (event === 'round:settled') {
    console.log(`[SETTLED] Round #${data.roundNumber} Winner: ${data.winnerFood.name}`);
    for (const player of data.players) {
      if (player.won) {
        console.log(`User ${player.sessionId} won ${player.winAmount}!`);
        // Credit player wallet in your DB
      }
    }
  }

  res.status(200).json({ received: true });
});

app.listen(8000, () => console.log('Webhook server active on port 8000'));
